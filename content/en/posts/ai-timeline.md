It's hard to grasp the progress of AI: you can try using benchmarks, but it's not an exact method.
Even though benchmarks are numbers and would be handy for measuring the progression of generative AI capabilities, it's enough to swap a saturated benchmark for another one to see the results change from one moment to the next.
That's what happens, for example, with every version of the Artificial Analysis benchmark suite I follow in other posts.

But here I'd like to rely on events that, in my opinion, proved a change in the results achieved by LLMs.

Let me start with a caveat: there's a difference between what is possible with an LLM, what is done for the first time with an LLM, and what is done by most people with LLMs. Here we'll focus mainly on what is done for the first time with LLMs.

## Timeline 1: new technologies for programming

{{< ai-timeline >}}

### The beginning

It all starts with ChatGPT: it was the one that made generative AI famous. From then on, people began to stop using Google or forums to get answers: from that moment they asked ChatGPT.

### + 6 months
Tool use is introduced: now you had a real agent that could use tools, such as a calculator or the weather.

### + 2 years
MCP is introduced: a standard was needed to integrate agents with tools.

### + 2 years and 3 months
After 2 years and 3 months, Claude Code is introduced: from that moment on, code could be written using an AI agent.
No more copy-pasting, testing the code and then pasting the errors into ChatGPT.
From then on the agent wrote the code, installed the libraries, ran the program and the tests.

### + 3 years and 1 month
After 3 years and 1 month, Skills arrive: our capabilities could be encoded as text inside skills.
The agent had the tools but lacked a way to learn new capabilities on the fly.
Of course these are just markdown files, not magic, but this really did add new capabilities to the models.
As models progressed, though, some capabilities were internalised and some skills are no longer needed.

### + 3 years and 3 months
After 3 years and 3 months comes the remote mode for Claude Code: now there's no need to sit at a PC, you can do everything from your phone; programming has become writing to an agent what it has to do, from your phone.

### + 3 years and 4 months
The Glasswing project is established after the release of Mythos. The model is not released to the public because it is too capable in cyber security: only selected companies can use it to harden their systems. From then on, every new model that is more capable in cyber security is released after consulting the US government.

### + 3 years and 5 months
The first rewrite of a widely used open source program using AI is carried out.
Bun is rewritten in Rust in a short time: what once took a long time, AI now does quickly and well.
Today Bun has migrated to Rust and there have been no major problems.

### Reflection
All these events have changed the way we use AI; clearly, over time these novelties have spread and are still spreading. There will be people who program without using an AI agent or without asking an AI chatbot.
There are, on the other hand, companies where 90% of the code is written using AI agents.

What can we predict for the future?

- We can see a future where most software will be rewritten in efficient and memory safe languages.
- We can also see a future where anyone publishing software will have to get it validated for security by an AI.
